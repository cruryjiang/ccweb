# 图片粘贴解析功能设计文档

日期：2026-03-04

## 概述

为当前系统增加图片粘贴解析能力，用户可以在页面任意位置粘贴图片，图片预览显示在输入框上方，配合文字一起发送给 Claude 分析。

## 需求总结

| 项目 | 决定 |
|------|------|
| 图片用途 | 发送给 Claude 分析 |
| 触发位置 | 整个页面监听粘贴事件 |
| 预览位置 | 输入框上方 |
| 发送方式 | 配合文字一起发送 |
| 图片数量 | 支持多张累积 |
| 图片管理 | 每张图片有单独删除按钮 |
| 大小限制 | 5MB（与后端一致） |

## 实现方案

### 方案选择：纯前端增强

只修改前端 JavaScript，完全复用现有 `/api/upload-image` 接口。

**优点**：
- 改动范围小，风险低
- 无需修改后端代码
- 符合 YAGNI 原则

### 文件改动

| 文件 | 改动内容 |
|------|----------|
| `static/index.html` | 添加图片预览区域 HTML 结构 + 粘贴事件监听 + 上传逻辑 |

### 前端模块设计

```
新增/修改模块：
├── 图片状态管理
│   ├── pendingImages[] - 存储待发送图片
│   ├── addImage() - 添加图片
│   └── removeImage() - 删除图片
│
├── 粘贴事件监听
│   └── document paste 事件处理
│
├── 图片预览 UI
│   ├── 渲染预览缩略图
│   └── 删除按钮交互
│
└── 发送逻辑修改
    └── 发送时遍历 pendingImages 调用上传 API
```

## 数据流设计

```
用户粘贴图片
    ↓
paste 事件捕获
    ↓
提取 DataTransfer 数据
    ↓
转换为 base64
    ↓
前端校验文件大小（≤5MB）
    ↓
存入 pendingImages 数组
    ↓
渲染预览 UI
    ↓
用户点击发送
    ↓
遍历 pendingImages 调用 /api/upload-image
    ↓
收集所有 image_id
    ↓
构造 ChatRequest 发送
    ↓
发送成功后清空 pendingImages
```

## UI 设计

### 预览区布局

```
┌─────────────────────────────────────────────────┐
│ [图片1 x] [图片2 x] [图片3 x]                    │  ← 预览区（输入框上方）
├─────────────────────────────────────────────────┤
│ ┌─────────────────────────────────────────────┐ │
│ │ 输入框                                       │ │
│ │                                             │ │
│ └─────────────────────────────────────────────┘ │
│                                    [发送按钮]    │
└─────────────────────────────────────────────────┘
```

- 缩略图横向排列
- 每个缩略图右上角有 × 删除按钮
- 缩略图大小建议：60x60 或 80x80 像素

### 粘贴成功提示

粘贴成功时，可在缩略图旁边显示简短提示（如"已添加图片"），或在页面顶部显示 toast 通知。

## 错误处理

| 场景 | 处理方式 |
|------|----------|
| 粘贴非图片数据 | 静默忽略，不干扰正常文字粘贴 |
| 图片超过 5MB | 显示错误提示："图片太大，请压缩后重试 (最大 5MB)" |
| 上传失败 | 显示错误提示，图片保留在预览区供重试 |
| 网络超时 | 同上传失败处理 |

## 测试场景

| 场景 | 预期结果 |
|------|----------|
| 粘贴单张图片 | 预览区显示缩略图 |
| 连续粘贴多张图片 | 预览区累积显示所有图片 |
| 粘贴非图片数据 | 静默忽略，正常文字粘贴不受影响 |
| 粘贴超 5MB 图片 | 显示错误提示，不加入预览区 |
| 点击图片删除按钮 | 该图片从预览区移除 |
| 发送成功后 | 预览区清空 |
| 上传失败 | 显示错误提示，图片保留 |
| 只粘贴图片不输入文字 | 允许发送，消息内容可以只有图片 |

## 实现注意事项

1. **事件监听时机**：确保在 DOM 加载完成后绑定 paste 事件
2. **base64 转换**：使用 FileReader 读取剪贴板中的 Blob 数据
3. **并发上传**：多张图片可以并行上传以提高效率
4. **UI 响应**：上传过程中可显示 loading 状态
5. **内存管理**：发送成功后清空 pendingImages 数组和相关 DOM
