# 自定义模型选择功能设计文档

**日期**: 2026-03-05
**状态**: 设计阶段

## 1. 需求背景

### 目标
支持为不同会话选择不同的模型，实现复杂任务用强模型（如 Opus），简单任务用快模型（如 Haiku）的性能优化。

### 用户选择汇总
| 问题 | 选择 |
|------|------|
| 目的 | B. 性能差异 - 复杂任务用强模型，简单任务用快模型 |
| 切换方式 | B. 手动切换 - 用户在前端界面选择 |
| 模型支持 | C. 配置文件自定义模型列表 |
| 配置格式 | B. JSON 文件 |
| 作用范围 | B. 会话级别 |
| 存储方案 | A. 会话配置文件独立存储 |
| 前端展示 | A. 下拉菜单 |

## 2. 架构设计

## 3. API 设计

### 3.1 获取模型列表

```
GET /api/models
```

**响应:**
```json
{
  "models": [
    {"id": "claude-opus-4-6", "name": "Claude Opus 4.6", ...}
  ],
  "default_model": "claude-sonnet-4-6"
}
```

### 3.2 获取会话模型

```
GET /api/session/{session_id}/model
```

**响应:**
```json
{
  "model": "claude-sonnet-4-6"
}
```

### 3.3 设置会话模型

```
POST /api/session/{session_id}/model
```

**请求体:**
```json
{
  "model": "claude-opus-4-6"
}
```

**响应:**
```json
{
  "status": "ok",
  "model": "claude-opus-4-6"
}
```

### 3.4 修改聊天接口

`POST /api/chat` 请求体新增 `model` 字段：

```json
{
  "session_id": "abc123",
  "message": "hello",
  "model": "claude-opus-4-6",
  ...
}
```

## 6. 数据流

```
用户选择模型
    ↓
前端调用 POST /api/session/{id}/model
    ↓
后端保存到 data/sessions/{id}.json
    ↓
用户发送消息
    ↓
前端携带 model 字段调用 POST /api/chat
    ↓
后端读取会话配置获取模型
    ↓
调用 claude CLI 时传递 --model 参数
```

## 7. 错误处理

| 场景 | 处理方式 |
|------|----------|
| models.json 不存在 | 返回内置默认模型列表 |
| 模型ID无效 | 使用默认模型，前端提示警告 |
| 会话配置文件损坏 | 创建新默认配置 |
| CLI 不支持指定模型 | 后端验证 CLI 版本，前端降级提示 |
